# 核保 / 健康告知 / 既往症基础知识

> 本文件为保险领域包权威生产语料（非测试数据）。事实表述以"通常/常见/一般为"限定，具体以投保时条款与核保结论为准。

## 1. 核保定位

核保是保险公司对被保人风险进行评估、决定是否承保及以何种条件承保的过程。健康告知是投保人对健康状况的如实陈述义务，是核保与后续理赔的重要依据。

## 2. 健康告知原则

健康告知通常遵循**有限告知/询问告知**原则：对保险公司明确询问的事项如实回答，未询问的可不主动披露。但隐瞒询问项可能导致理赔纠纷乃至合同解除。

## 3. 既往症

既往症指被保险人在投保前已患或应当知晓的疾病/症状。医疗险、重疾险通常对既往症有**责任除外或等待期/健康告知**约束；未如实告知既往症可能影响理赔。

## 4. 核保结论类型

常见核保结论：标准体承保、加费承保、除外责任承保、延期、拒保。不同险种、不同产品对相同健康状况的结论可能不同。

## 5. 与理赔的关系

健康告知与核保结论是理赔时核实"投保时是否如实告知"的基准。存在未如实告知且足以影响承保决定的，保险公司可依法解除合同或拒赔。
