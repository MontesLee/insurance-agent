# 重疾需求 维度

## A. 必填事实维度

- `annual_income` 年收入
- `family_responsibility` 家庭责任

两项齐备才产出重疾结论。

## B. 需求口径与缺口计算

- 公式名：`ci_50w_plus_income_x3`
- 口径：50 万基础 + 年收入 ×3（覆盖治疗费用 + 康复期收入中断）
- 已有保障取自 `existing_critical_illness_coverage`。

## C. 优先级档位

| 情形 | 档位 |
|------|------|
| 已有保障信息不可分析 | P1_HIGH |
| 客户明确确认零保障 | P0_CRITICAL |
| 有保障且 ≥ 需求估算 | P2_MEDIUM |
| 有保障但 < 需求估算 | P1_HIGH |

设计要点：不因"存在任何保障"就机械降档；足额才降档，未足额维持高优先级。

## D. 本险种特有的边界红线

- 不计算或建议具体重疾保额。
- 不预判核保结论或理赔结论。
