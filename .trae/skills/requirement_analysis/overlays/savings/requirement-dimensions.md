# 储蓄与长期目标需求 维度

## A. 必填事实维度

- `annual_income` 年收入
- `annual_expense` 年支出
- `liabilities` 负债
- `cash_flow` 现金流
- `financial_goals` 财务目标

五项齐备才产出储蓄结论；资产状况取自 `assets`（影响充分性判断，不阻断结论）。

## B. 需求口径与缺口计算

- 公式名：`none`
- 判定方式：收支、负债、现金流与目标共同决定长期积累空间；资产不明时方向可判、充分性不可判。

## C. 优先级档位

| 情形 | 档位 |
|------|------|
| 资产状况可分析 | P2_MEDIUM |
| 资产状况不可分析 | P1_HIGH |

## D. 本险种特有的边界红线

- 不推荐具体理财或年金产品。
- 不预测投资收益率。
