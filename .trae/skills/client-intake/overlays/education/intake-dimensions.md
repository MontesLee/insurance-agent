# 教育金 — 信息采集维度

> Overlay `education`（status: draft）。只定义**多问什么**与**怎么记录**，不定义任何判断。
> draft 状态不会被自动激活，需补 Eval 用例后才转 active。

## A. 必填维度（激活且经客户确认后，进入 intake_complete 判定）

| 维度 | 为什么需要 | 记录口径 |
|---|---|---|
| 子女数量与年龄 | 领取时间锚点 | 每个孩子分别记 |
| 当前教育阶段 | 判断储备窗口 | 学前/小学/初中/高中/大学/已工作 |
| 教育路径意向 | 决定目标金额量级差异 | 国内公立/国内国际/出国留学/未定 |
| 目标使用节点 | 领取时点设计 | 客户表述，如"大学时用""高中就出去" |
| 已储备教育金情况 | 缺口判断 | 客户自述：专项存款/理财/保险/无 |

## B. 建议维度（不阻塞 intake_complete）

| 维度 | 为什么需要 | 记录口径 |
|---|---|---|
| 目标金额区间（客户自述） | 方案设计输入 | 客户表述；**Intake 不测算** |
| 投保人意向 | 影响豁免责任安排 | 父母/祖辈/未定 |
| 是否关注投保人豁免 | 客户顾虑点 | 客户表述 |
| 缴费期偏好 | 方案设计输入 | 客户表述 |
| 是否要求特定年龄可领取 | 领取灵活性 | 客户表述 |
| 是否有二胎/三胎计划 | 分配安排 | 客户自述 |
| 家庭年结余量级 | 可投入上限 | 客户表述 |

## C. 触发后可一并确认的关联信息

- 父母年龄与职业稳定性（缴费期窗口）
- 家庭负债（教育金与负债的优先级冲突）
- 是否同时关注子女医疗/重疾（同一被保险人的多险种需求）

## D. 本险种特有的边界红线

- **禁止预测学费。** 客户问"留学得准备多少" → 说明这取决于国家、学校、年份，建议以官方公布数据为准，Intake 不代算。
- **禁止算缺口、建议金额。**
- **禁止评价教育路径。** 不说"留学性价比不高""国际学校更好"，只记录客户意向。
- **禁止建议缴费金额。**

## E. 常见误判提醒

- 客户说"给孩子存点钱"不一定是教育金 —— 可能是传承或一般性储蓄，需确认用途再激活。
- 教育金的被保险人（子女）与投保人（父母）不同，采集时务必分清字段归属。
- 子女年龄直接决定储备窗口，误记会导致后续测算全错，必须取客户原话数值。
