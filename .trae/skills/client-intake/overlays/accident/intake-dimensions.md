# 意外险 — 信息采集维度

> Overlay `accident`。只定义**多问什么**与**怎么记录**，不定义任何判断。

## A. 必填维度（激活且经客户确认后，进入 intake_complete 判定）

| 维度 | 为什么需要 | 记录口径 |
|---|---|---|
| 职业与岗位（自述） | 职业是意外险投保的核心变量 | 客户自述岗位与主要工作内容。**H3 要求采集到"足以判断职业"的深度**（即问清岗位与是否涉及高危作业），但**分类结论不由 Intake 下** |
| 是否涉及高危作业 | 影响可投产品范围 | 客户自述：高空/井下/机械操作/危化品/无 |
| 现有意外保障 | 缺口判断 | 有/无/不清楚；含团体意外、工伤、学平险 |
| 关注侧重 | 区分意外医疗与伤残身故 | 客户原话，如"主要怕磕碰看门诊"或"怕出大事" |

## B. 建议维度（不阻塞 intake_complete）

| 维度 | 为什么需要 | 记录口径 |
|---|---|---|
| 日常通勤方式 | 场景频次事实 | 自驾/地铁公交/步行/骑行；客户自述 |
| 年驾驶里程 | 同上 | 客户自述量级 |
| 出差频率与交通方式 | 同上 | 客户自述，如"每月飞两次" |
| 高频运动/爱好 | 部分产品除外高风险运动 | 客户自述具体项目，不评价危险程度 |
| 是否关注意外医疗（门诊） | 责任范围偏好 | 客户表述 |
| 是否有社保外用药需求 | 责任范围偏好 | 客户表述 |
| 家庭成员是否都需要 | 家庭投保范围 | 客户表述 |
| 老人跌倒风险顾虑 | 老年意外场景 | 客户表述（事实，不做风险评价） |

## C. 触发后可一并确认的关联信息

- 常驻城市与就医习惯（意外医疗的医院范围）
- 是否已有工伤保险（单位缴纳）
- 子女是否在校（学平险可能已覆盖）

## D. 本险种特有的边界红线

- **禁止判定职业类别。** 客户说"我是电工" → 记录 `客户自述：电工，涉及配电作业`，不写 `职业类别：4类`。
  采集深度按通用层 H3（要能让下游判断职业），但**分类权在保险公司**，Intake 只交付原话事实。
- **禁止评价危险程度。** 客户说"我周末玩攀岩" → 记事实，不接"这个挺危险的"。
- **禁止预判是否除外。** 客户问"攀岩能保吗" → "这要看产品的责任免除，我这边不下结论"。
- **禁止算保额。**

## E. 常见误判提醒

- "意外"在客户口中有时指"突发重疾"（如"我怕突然得个什么病"）—— 那是重疾/医疗需求，需在确认环节澄清。
- 意外险与医疗险在"意外医疗"上重叠，按客户关注侧重归类，不要重复采集。
- 职业类别是硬约束，采集务必用客户原话，任何归纳都可能出错。
