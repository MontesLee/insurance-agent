# 财富传承 / 终身寿 — 信息采集维度

> Overlay `inheritance`（status: draft）。只定义**多问什么**与**怎么记录**，不定义任何判断。
> draft 状态不会被自动激活，需补 Eval 用例后才转 active。

## A. 必填维度（激活且经客户确认后，进入 intake_complete 判定）

| 维度 | 为什么需要 | 记录口径 |
|---|---|---|
| 传承首要目标 | 决定方案方向 | 客户原话：定向传承/资产隔离/税务规划/企业风险隔离/未明确 |
| 家庭结构复杂度 | 继承关系的事实基础 | 婚姻状况、子女人数与年龄、是否再婚、是否有非婚生子女/继子女 |
| 拟传承资产类型 | 方案设计输入 | 客户自述量级与类型：不动产/股权/现金金融/其他 |
| 受益人意向 | 投保必需 | 客户表述的人员范围与大致比例；**不代客户决定** |
| 是否存在企业经营或对外担保 | 债务隔离需求的事实基础 | 客户自述，只记事实不评价风险 |

## B. 建议维度（不阻塞 intake_complete）

| 维度 | 为什么需要 | 记录口径 |
|---|---|---|
| 是否关注婚姻风险（子女婚前财产） | 客户需求点 | 客户表述 |
| 是否有跨境资产或外籍家庭成员 | 方案复杂度 | 客户自述 |
| 是否有遗嘱/家族信托 | 已有安排去重 | 有/无/不清楚 |
| 现有终身寿或大额保单 | 已有保障去重 | 客户自述保额量级 |
| 流动性需求 | 资金安排约束 | 客户表述 |
| 缴费期与年缴预算 | 方案设计输入 | 客户表述 |
| 是否愿意接受长期锁定 | 方案形态偏好 | 客户表述 |

## C. 触发后可一并确认的关联信息

- 客户年龄与健康状况自述（终身寿投保窗口与核保）
- 家庭年结余与可投资资金量级
- 是否有律师/税务师/ accountant 已介入（避免越界给专业意见）

## D. 本险种特有的边界红线

- **禁止给法律/税务意见。** 客户问"这样能避税吗""遗嘱怎么写有效" → 标准回复：这属于法律与税务专业范畴，建议咨询您的律师或税务师，我这边如实记录您的目标。
- **禁止预判政策。** 客户问"遗产税会不会开征" → 记为客户关注点，不给结论。
- **禁止评价家庭关系。** 不说"这种情况最好早做安排""不安排以后容易有纠纷"，只记录事实与目标。
- **禁止建议架构或保额。**

## E. 常见误判提醒

- 高净值客户的"传承"诉求往往与"资产隔离"并存，需确认首要目标再归类。
- 家庭结构信息高度敏感，客户可能不愿展开 —— 拒绝则记 `declined`，**不得追问第二次**（通用层规则）。
- 本 overlay 涉及的信息若客户主动提及纠纷、诉讼，只记客户表述，不做任何判断或站队。
