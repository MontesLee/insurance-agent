# 寿险 — 信息采集维度

> Overlay `life`。只定义**多问什么**与**怎么记录**，不定义任何判断。

## A. 必填维度（激活且经客户确认后，进入 intake_complete 判定）

| 维度 | 为什么需要 | 记录口径 |
|---|---|---|
| 主要收入贡献者 | 寿险保额的责任锚点 | 本人/配偶/共同；客户自述 |
| 家庭负债总额与结构 | 身故后需覆盖的刚性支出 | 分项记：房贷余额/年限、车贷、消费贷、经营贷；客户自述数值 |
| 子女抚养责任 | 责任年限与年支出 | 子女年龄、预计独立年限、年支出量级 |
| 父母赡养责任 | 同上 | 父母年龄、是否需长期赡养、年支出量级 |
| 现有寿险保障 | 缺口判断 | 有/无/不清楚；有则记客户自述保额量级 |
| 单位是否有团体寿险/工伤 | 已有保障去重 | 有/无/不清楚 |

## B. 建议维度（不阻塞 intake_complete）

| 维度 | 为什么需要 | 记录口径 |
|---|---|---|
| 收入替代年限预期 | 下游测算输入 | 客户表述，如"希望够家里撑 10 年" |
| 定期/终身形态偏好 | 方案设计输入 | 客户表述；Intake 不解释两者差异 |
| 是否关注全残责任 | 责任范围偏好 | 客户表述 |
| 受益人意向 | 投保必需 | 客户表述的人员范围与大致比例；不代客户决定 |
| 是否有企业经营/对外担保 | 债务风险事实 | 客户自述，只记事实不评价风险 |
| 缴费期偏好 | 方案设计输入 | 客户表述 |

## C. 触发后可一并确认的关联信息

- 配偶收入与职业（双收入家庭的责任分摊）
- 家庭年支出量级（收入替代的计算基数）
- 婚姻状况与婚前/婚后财产情况（涉及受益人安排）

## D. 本险种特有的边界红线

- **禁止算保额。** 客户问"我该买多少" → 标准回复：这需要把负债、子女教育、父母赡养、收入替代年限一起算，分析环节给您完整依据。
- **禁止评价责任轻重。** 不说"您这房贷压力挺大的"，只记录事实数值。
- **禁止指定受益人。** 只记录客户意向，不引导、不推荐分配比例。
- **禁止把负债当风险结论。** 记"房贷余额 300 万"，不记"家庭财务风险高"。

## E. 常见误判提醒

- 客户提到"房贷"可能只是陈述生活状况，未必是寿险需求 —— **先确认关注点再激活**。
- 全职太太/先生同样有家庭责任（替代家政与照护成本），不要默认收入为零则无需寿险。
- 寿险与重疾常被混谈（"大病走了也能赔"），按客户原话分别记入两个 overlay。
