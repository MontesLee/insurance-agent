# KB v1.0 Chunk Policy(分层)

| Layer | chunk 单元 | 规则 |
|---|---|---|
| L1 | 章→节→**条** | 一条法律规定保持完整;禁止为固定 token 数强切条文 |
| L2/L3 | 主题→子主题→概念 | 概念单元完整(如「重疾险:定义/保险责任/等待期/轻症/中症/多次赔付」各自成块) |
| L4 | 疾病/核保主题→判断因素→常见处理→限制 | 核保判断单元完整 |
| L5 | 规划目标→输入变量→方法→示例→限制 | 方法单元完整 |

通用:chunk 边界不得切断一个完整命题;跨 chunk 命题在导入前
必须调整切分(当前 WeKnora 自动切分——偏差记录于验收文档)。
